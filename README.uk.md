# Typix

[English](README.md)

Typix це додаток для екранного читача NVDA, який відтворює звук для кожної клавіші, що ви натискаєте в текстовому полі. Літери, великі літери, пробіл, Enter, Tab, Backspace, Delete і розділові знаки можуть мати окремі звуки, а кожен символ може мати власне положення в стереопанорамі та власну висоту.

Typix також може подати сигнал, коли ви закінчили слово з помилкою, запропонувати виправлення, замінити скорочення на довший текст, сказати ціле слово після виправлення й повідомити швидкість набору.

Інтерфейс і довідка доступні англійською та українською.

## Встановлення

Для роботи потрібна NVDA 2026.1 або новіша.

1. Завантажте найновіший файл `.nvda-addon` зі [сторінки випусків](../../releases).
2. Відкрийте файл і підтвердьте встановлення.
3. Перезапустіть NVDA.

Налаштування є в діалозі налаштувань NVDA, у категорії Typix. Дві команди не мають клавіш за замовчуванням; призначте їх у діалозі Жести вводу, у категорії Typix.

## Довідка

Повна довідка є [українською](doc/uk/readme.md) та [англійською](doc/en/readme.md). У NVDA вона відкривається з Магазину додатків, на вкладці встановлених додатків.

## Приватність

Typix виходить в інтернет лише для того, щоб завантажити словник зі словників LibreOffice на GitHub, коли ви вперше використовуєте мову. Те, що ви вводите, нікуди не надсилається. Статистика набору містить лише числа й зберігається в папці конфігурації NVDA.

## Переклад

Кожна мова має один файл, `locale/<мова>/LC_MESSAGES/nvda.po`, який можна редагувати в Poedit або іншому редакторі файлів .po.

Щоб почати нову мову, відкрийте `locale/typix.pot` у Poedit через New from POT/PO file, виберіть мову й збережіть файл як `locale/<мова>/LC_MESSAGES/nvda.po`. Кожен рядок має примітку про те, де він з'являється. Не змінюйте заповнювачі на зразок `{name}`. Літера після амперсанда це клавіша швидкого доступу, тож виберіть зручну для вашої мови й не повторюйте її в одному діалозі. Довідка розміщується в `doc/<мова>/readme.md`.

## Збірка

Потрібні Windows, Python і Babel (`pip install babel`).

```
build.bat
```

Скрипт підвищує номер версії в `manifest.ini`, перетворює довідку на HTML, компілює переклади й записує пакет у папку `dist/`.

Після зміни тексту інтерфейсу виконайте `python tools/i18n.py update`. Ця команда оновлює шаблон і об'єднує його з усіма мовами.

## Тести

Тести це звичайні скрипти unittest. Кожен запускається окремо, наприклад:

```
python tests/test_sound_loader.py
```

Вони охоплюють код, якому не потрібна NVDA. Усе в `__init__.py` і `settings.py` треба перевіряти в самій NVDA.
